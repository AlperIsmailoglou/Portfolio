The workflow began by placing front and side reference images onto active sketch planes inside Creo. Using these visual guides, precise curve profiles were traced for the blade serrations, top thumb ramp, and handle finger grooves. Once the main profiles were established, solid extrusions and angled bevel cuts formed the sharp cutting edge and top serration details. Ergonomic handle scales were then built to fit around the tang. The project concluded with studio rendering, featuring a polished stainless steel blade and matte composite handle.
